# 프로젝트명: 나곡중 1학년 영어 교과서 표현 학습 미니앱
# 목적: 최소한의 UI로 영어 표현을 학습시키고, 전면/보상형 광고를 통해 수익을 극대화한다.

## 1. 핵심 화면 구성 (단일 페이지 웹앱 / 웹뷰 최적화)
- 메인 화면: 1과부터 4과까지 선택할 수 있는 4개의 큰 버튼 배치
- 학습 화면: 선택한 단원의 영어 표현이 한 화면에 한 문장씩 크게 노출 (카드 형태)
- 광고 팝업: 특정 조건 만족 시 화면 전체를 덮는 광고 유도 레이어 노출

## 2. 사용자 기능 흐름 (User Flow)
1. 사용자가 메인 화면에서 [Lesson 1]을 클릭한다.
2. 1번 문장이 화면에 나타난다. 화면을 터치(클릭)하면 2번 문장으로 넘어간다.
3. 3번 문장까지 보고 다음으로 넘어가려고 하면 화면이 잠기며 팝업이 뜬다.
4. [광고 보고 나머지 표현 잠금 해제] 버튼을 눌러야만 다음 문장을 볼 수 있다.
5. 단원의 모든 문장(5개)을 다 보면 다시 메인 화면으로 돌아가는 버튼이 노출된다.

## 3. 디자인 가이드 (토스 스타일)
- 배경색: 순백색 (#FFFFFF) 또는 라이트 그레이 (#F2F4F6)
- 글자색: 볼드한 네이비/블랙 (#191F28)
- 버튼: 라운드가 들어간 블루 포인트 버튼 (#3182F6)
- 미니멀리즘: 불필요한 데코레이션, 메뉴바, 뒤로가기 버튼을 최소화하여 콘텐츠와 광고에만 집중하게 함.
