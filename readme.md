# 🎒 나곡중 1학년 영어 교과서 표현 학습 미니앱

> **Apps in Toss (앱스인토스) 플랫폼 전용 초경량 Native App Bundle 미니앱**  
> 비전공 1인 개발자가 최신 빌드 자동화 파이프라인을 연동하여 최소한의 자원으로 플랫폼 광고 매출을 극대화하도록 설계한 상용급 마이크로 웹 인프라 자산입니다.

---

## 🚀 1. 핵심 아키텍처 특징 (Core Values)
- **Xcode / Gradle 방식 컴파일**: 웹 소스코드를 그대로 호스팅하는 주소 매핑 방식을 탈피했습니다. 토스 그래나이트(Granite) 컴파일러를 가동해 암호화 패키징된 독자적 모바일 바이너리 확장자 파일(`.ait`)을 안전하게 빌드해 냅니다 [💬].
- **100% 서버리스 구조 (Serverless)**: 가입 절차나 실시간 중앙 백엔드 DB 서버 의존성을 완전히 제거하여 인프라 유지 고정 비용을 0원으로 수렴시켰습니다. 학습 상태값은 브라우저 샌드박스 내부의 `localStorage`를 점유하여 격리 처리됩니다.
- **TDS (토스 디자인 시스템) 동기화**: 공식 컬러셋인 `#3182F6 (토스블루)`를 메인 테마로 입히고, 깊게 라운딩 처리된 컨테이너 블록 스타일을 적용해 인앱(In-App) 구동 시 이질감 없는 환경을 유지합니다.
- **고전단 보상형 광고 루프 (🔒)**: 단원별 3번째 문장을 열람하는 즉시 `window.toss.showRewardAd` 핸드셰이크를 호출하여 모달을 잠금 처리합니다. 사용자의 학습 완수 욕구와 토스 광고 시스템을 결합하여 클릭당 단가(eCPM) 정산 수익을 극대화합니다.

## 🛠️ 2. 사용 엔지니어링 스택
- **하드웨어 디바이스**: M1 Mac Mini (Apple Silicon 최적화 워크스페이스 세팅)
- **개발 환경 엔진**: Node.js `v22.22.1` / NPM `11.12.1`
- **핵심 컴파일 프레임워크**: HTML5 / Vanilla JavaScript (ES Modules) / Tailwind CSS v3 Engine
- **빌드 및 패키징 자동화**: Vite `v8.x.x` 및 `@apps-in-toss/web-framework` 번들러 링커
- **버전 관리 인프라**: Git / GitHub CLI (`gh`)

## 📂 3. 디렉토리 구조 (Directory Directory Architecture)
```text
toss-english-app/
├── assets/images/       # 플랫폼 승인 심사용 규격 규격 디자인 파일들 (.png)
├── doc/                 # 1인 개발 라이프사이클 유지보수용 소울 문서군
│   ├── PRD.md           # 기능 상세 명세 및 수익 비즈니스 모델 정의서
│   ├── ARCHITECTURE.md  # 이벤트 바인딩 해법 및 컴파일러 환경 설정 가이드
│   ├── DEPLOYMENT.md    # 그래나이트 아티팩트 빌드 및 검수 정보 제출 명세
│   ├── instruction.md   # 🌟 AI 프롬프트 가이드 (Vite 인라인 코드 유실 방지 필터)
│   └── skill.md         # 🌟 터미널 콘솔 명령어 치트시트 및 긴급 복구 지침
├── dist/                # Vite가 리팩토링한 배포용 임시 파일 수납 디렉토리
├── index.html           # 애플리케이션 프론트엔드 엔트리 뷰포트
├── app.js               # 상태 제어 및 자바스크립트 이벤트 매트릭스 코어
├── granite.config.ts    # 🌟 타입스크립트 기반 토스 빌더 규격 바인딩 설정서
├── .gitignore           # 로컬 캐시 및 시스템 노출 방지 파일 마스킹 마스크
└── package.json         # NPM 스크립트 커맨드 명세서
```

## 🏃‍♂️ 4. 통합 구동 사이클 치트시트
새로운 소스코드 개정판을 패키징하여 토스 공식 대시보드에 업로드할 때 가동하는 콤보 커맨드입니다. (상세 내역은 `doc/skill.md` 참조)

```bash
# 1. 로컬 가상 환경 디버그 가동
npm run dev

# 2. 토스 플랫폼 전용 바이너리 아티팩트 파일(.ait) 추출 컴파일
npm run build
# ➡️ 결과물: nagok-m01-english.ait (해당 파일을 토스 콘솔 버전에 드래그 업로드)
```
